PUBERTY & VR SCRIPT CATALOG
===========================

Shared modules
--------------
project_paths.py
    Defines all paths relative to the project directory. Scripts can be run from
    any working directory.

file_naming.py
    Parses and generates canonical subject, pLearning CSV, and pLearning JSON
    names. Learning scripts accept only ###_plearning_[12].csv.

learning_utils.py
    Contains the shared exponential learning function P(t) = a - b*exp(-k*t).

Setup and validation
--------------------
standardize_file_names.py
    Dry-run by default. Standardizes raw filenames and records every decision in
    data/metadata/rename_log.csv. Use --apply only after reviewing conflicts.

rename_jsons.py
    Focused, optional alternative that standardizes pLearning JSON names only.

raw_data_inventory.py
    Creates the filename dictionary, subject-level inventory, recognized raw-file
    index, missing-file report, and unrecognized-file report.

validate_raw_data.py
    Checks EEG/heart-rate schemas, detects exact duplicate content within each
    subject folder, and carries filename conflicts into
    data/metadata/raw_data_quality_issues.csv.

process_jatos_python.py
    Recursively finds pLearning JSON files by default, converts each to a canonical
    trial-level CSV, and updates subject_info_summary.csv by subject and session.
    Custom --output-dir and --summary-path arguments are honored.

Modality summaries
------------------
summarize_heart_rate.py
    Parses Polar CSV exports with an embedded HR (bpm) header and produces long and
    wide heart-rate summaries in data/analysis_data/heart_rate/.

summarize_eeg.py
    Summarizes Mind Monitor CSV or single-CSV ZIP files. Files without expected EEG
    columns are marked invalid instead of counted as available.

Behavioral analyses
-------------------
calculate_learning_rates.py
    Fits P(t) = a - b*exp(-k*t) for every subject/session and writes
    data/analysis_data/learning_rates/learning_rates.csv. Session 1 learner_group is
    the source of truth for all downstream good/bad comparisons.

all_individuals_with_curve.py
    Saves trial-wise subject proportions, fitted-versus-observed diagnostics, and
    all-subject/group-average learning-curve figures.

first_half_vs_second_half.py
    Compares blocks 1-5 with blocks 6-10 using paired summaries and individual/group
    curve figures.

individual_first_vs_second_halves.py
    Creates one first-half versus second-half curve figure per Session 1 subject.

group_average_by_winner.py
    Plots group learning curves split by set-winner type (face versus house).

learning_rate_analysis.py
    Produces subject/session summaries, AUC values, individual comparisons, group
    curves, good/bad comparisons, and subject-versus-group figures.

learning_slope_analysis.py
    Creates trial-level data, subject/session linear slopes, paired slope tests, a
    Gaussian mixed model, and related figures/reports. See README statistical notes
    before using the mixed-model p-values for confirmatory inference.

learning_summary_statistics.py
    Pairs Trial 1 and Trial 18 explicitly by subject and writes descriptive/paired
    t-test results to outputs/learning_rates/reports/.

plot_group_average_curve.py
    Generates exponential group-average curves for good, bad, and all learners.

plot_individual_learning_curves.py
    Generates classified Session 1 individual curves with the group average overlay.

winstay_loseswitch_analysis.py
    Computes conditional P(stay | previous gain) and P(switch | previous loss).
    Overall subject scores pool all eligible transitions; trial-wise values retain
    position-specific denominators.

group_winstay_loseswitch_sessions.py
    Compares Session 1 and Session 2 strategy scores for all, good, and bad learners.
    Run after winstay_loseswitch_analysis.py.

Multimodal
----------
build_multimodal_dataset.py
    Merges behavioral, heart-rate, EEG-availability, and JATOS metadata into one row
    per subject/session. Session metadata is joined on both subject and session.

compare_minors_to_older.py
    Reads the first-column N/A Minor labels from Real_Subject_Data_ID.xlsx, joins
    them to the multimodal dataset, verifies that at least five distinct minor
    subjects are analyzable, and compares minor with older subjects. Subject-level
    variables are tested once per person and within-subject variables separately by
    session. Outputs include cohort mappings, descriptive availability, Welch/Fisher
    tests, effect sizes, and Benjamini-Hochberg FDR-adjusted p-values.

summarize_minor_comparison.py
    Creates a focused key-results table, explicit win-stay/lose-switch usage counts,
    a plain-language major-findings report, and learning, strategy, heart-rate, and
    standardized-effect figures from the full minor-comparison outputs.
