================================================================================
OUTPUT EXPLANATIONS – Learning Rates Analysis
================================================================================

This document describes the outputs generated by the Python scripts in the
`scripts/` folder. All outputs are saved inside the `outputs/` directory unless
otherwise noted.

--------------------------------------------------------------------------------
1. /all_individuals/
   Created by: all_individuals_with_curve.py
   Contains:
     - individual_proportions_session1.csv
         Columns: subject, trial (1‑18), proportion_correct
         Raw proportions of choosing the set‑winner, averaged across all blocks.
     - all_individuals_with_curves_sess1.png
         One figure showing every subject’s observed points (dots) and their
         individually fitted exponential curve (lines). Each subject is a
         different colour; a legend is included if the number of subjects ≤20.

--------------------------------------------------------------------------------
2. /bad_learners/
   Created by: bad_learners_only.py
   Contains:
     - bad_learners_curves_sess1.png
         Single figure showing only subjects classified as “bad” learners
         (based on median split of learning rate k). Each subject’s observed
         points and exponential fit are overlaid. A legend identifies each
         subject.

--------------------------------------------------------------------------------
3. /good_learners/
   Created by: good_learners_only.py
   Contains:
     - good_learners_curves_sess1.png
         Same as above but for “good” learners only.

--------------------------------------------------------------------------------
4. /half_comparison/
   Created by: first_half_vs_second_half.py
   Contains ten files comparing blocks 1‑5 (first half) with blocks 6‑10
   (second half). All plots use exponential fits with shaded SEM bands.
   Files:
     - boxplot_first_vs_second.png
         Boxplot comparing overall proportion correct between the two halves.
         Paired t‑test results printed to the console.
     - group_average_first_half.png
         Group average curve (exponential fit) for blocks 1‑5.
     - group_average_second_half.png
         Group average curve (exponential fit) for blocks 6‑10.
     - overlay_group_average_curves.png
         Overlay of the two group average curves (first half vs second half).
     - all_individuals_first_half.png
         All individuals’ observed points + exponential fits for blocks 1‑5.
     - all_individuals_second_half.png
         Same for blocks 6‑10.
     - good_vs_bad_first_half.png
         Overlay of good learners (green) vs bad learners (red) for blocks 1‑5.
     - good_vs_bad_second_half.png
         Same for blocks 6‑10.
     - good_first_vs_second.png
         For good learners only: overlay of their performance in blocks 1‑5 vs
         blocks 6‑10.
     - bad_first_vs_second.png
         Same for bad learners only.

--------------------------------------------------------------------------------
5. /individual_half_comparison/
   Created by: individual_first_vs_second_halves.py
   Contains:
     - subject_<id>_first_vs_second_half.png (one per subject)
         For each subject, a single plot overlaying their learning curve from
         blocks 1‑5 (blue) and blocks 6‑10 (red). Both halves use exponential
         fits (if enough data points). Observed points are shown.

--------------------------------------------------------------------------------
6. /individual_plots/
   Created by: individual_plots_with_classification.py

         Full trial‑by‑trial data with group labels.

         Individual plot showing observed points, exponential fit, and annotated

--------------------------------------------------------------------------------
7. /individual_vs_average/
   Created by: individual_vs_average.py
   Contains:
     - subject_<id>_vs_average.png (one per subject)
         For each subject, a plot that overlays:
           * The subject’s own curve (blue: observed points + exponential fit)
           * The group average curve (gray: exponential fit with shaded SEM
             band) computed from all subjects.
         The subject’s classification and fitted parameters are annotated.

8. group_average_exponential_learning_curves.png
   Created by: plot_group_average_curve.py
   Saved directly in the `learning_rates` folder (not inside `outputs/`).
   Description:
     Single figure showing the exponential learning curves for two groups:
     good learners (green) and bad learners (red), based on a median split of
     individual learning rates (k). Shaded bands represent ±1 SEM.

--------------------------------------------------------------------------------
9. learning_rates.csv
   Created by: calculate_learning_rates.py
   Saved in the `learning_rates` folder.
   Description:
     CSV file with one row per subject per session. Columns:
       - subjectId
       - plearning_num (session number, e.g., 1 or 2)
       - learning_rate_k (the fitted logistic learning rate; NaN if fit failed)
       - n_trials (total number of trials, should be 180)
       - mean_accuracy (overall proportion correct across all trials)
   This file is used by several other scripts for classification and plotting.

10. /learning_rate_analysis/
    Created by: learning_rate_analysis.py
    Contains:
        - median_learning_rates_summary.csv
            One row per subject plus an “AVERAGE” row. Columns: subject, sess1_t1…sess1_t18,
            sess2_t1…sess2_t18 (proportion correct on each trial), median_sess1, median_sess2,
            diff_s2_minus_s1 (session2 median minus session1 median), dev_s1, dev_s2
            (deviation of the subject’s median from the group average).
        
        - individual_s1_vs_s2/ (one PNG per subject)
            Graph: x‑axis = trial number (1‑18), y‑axis = proportion choosing set‑winner (0‑1).
            Blue points = observed proportions session 1, blue line = exponential fit for session 1.
            Red points = observed proportions session 2, red line = exponential fit for session 2.
            Dashed gray line = chance (0.5). Allows direct comparison of learning curves between the two sessions for each subject.
        
        - individual_with_group_avg/
            * subject_<id>_with_group_avg.png
                Same axes as above. Subject’s own data: blue points + fit for session 1, red points + fit for session 2.
                Overlaid are group average curves: darkgreen squares + dashed fit for session 1, orange squares + dashed fit for session 2.
                Shows how the subject compares to the group average in both sessions.
            * subject_<id>_sess1_vs_group.png – subject session 1 (blue) vs group session 1 (darkgreen).
            * subject_<id>_sess2_vs_group.png – subject session 2 (red) vs group session 2 (orange).
        
        - group_average/
            * group_average_curves.png
                x‑axis = trial number, y‑axis = proportion correct.
                Blue points and line = session 1 group average with exponential fit; red = session 2.
                Shaded bands = ±1 standard error of the mean (SEM) around the fitted curves.
                Chance line at 0.5.
            * group_scatter_session1.png and group_scatter_session2.png
                Scatter plot: each point is the group average proportion correct on a given trial,
                split by the identity of the set‑winner (blue = winner was “face”, red = winner was “house”).
                Overlaid gray line = exponential fit to the overall group average (all trials).
                Reveals whether performance differs depending on which stimulus was the set‑winner.
        
        - subject_vs_group_sd/ (one PNG per subject per session)
            x‑axis = trial number, y‑axis = proportion correct.
            Blue points = subject’s observed proportions; blue dashed line = subject’s exponential fit.
            Gray squares = group average proportion correct at each trial; error bars = ±1 standard deviation of the group.
            Gray dashed line = exponential fit to the group average.
            Allows assessment of how the subject’s performance deviates from the group spread.
        
        - group_comparisons/
            * good_learners_s1_vs_s2.png – group average curves for good learners only: session 1 (blue) vs session 2 (red), with shaded SEM bands.
            * bad_learners_s1_vs_s2.png – same for bad learners.
            * good_vs_bad_s1.png – session 1: good learners (green), bad learners (red), and overall group average (gray), each with shaded SEM.
            * good_vs_bad_s2.png – same for session 2.
            These plots show how the two subgroups differ in learning trajectories and whether they improve across sessions.

11. /winstay_loseswitch/
    Created by: winstay_loseswitch_analysis.py
    Contains:
        - winstay_loseswitch_summary.csv
            Columns: subject, sess1_t2_winstay … sess1_t18_winstay, sess1_t2_loseswitch … sess1_t18_loseswitch,
            similarly for session 2, plus overall_winstay_sess1, overall_loseswitch_sess1, etc.
            Values are conditional proportions (0‑1): win‑stay = P(stay | previous trial gain);
            lose‑switch = P(switch | previous trial loss). Trial 1 excluded because no previous feedback.
        
        - subject_bars_per_session/ (one PNG per subject)
            Bar graph with two groups of bars (session 1 and session 2). For each session:
            green bar = overall win‑stay proportion, red bar = overall lose‑switch proportion.
            Y‑axis = conditional proportion (0‑1). Allows quick comparison of strategy use between sessions.
        
        - subject_trial_by_trial/ (one PNG per subject per session)
            For a given subject and session, bar graph with trial numbers 2‑18 on the x‑axis.
            For each trial, two bars: green = win‑stay proportion, red = lose‑switch proportion.
            Reveals how the conditional strategies evolve trial‑by‑trial (e.g., early vs late learning).
        
        - group_average_bars_per_session/
            Bar graphs (session 1 and session 2 separately) showing the group average win‑stay (green) and lose‑switch (red) proportions.
            Y‑axis = conditional proportion (0‑1). Summarises overall strategy tendencies for the whole sample.
        
        - group_average_trial_by_trial/
            For each session, bar graph with trial numbers 2‑18; for each trial, green bar = group average win‑stay, red bar = group average lose‑switch.
            Shows the evolution of win‑stay and lose‑switch at the group level across trials.
        
        - good_vs_bad_by_feedback/ (one PNG per session)
            Paired bar plot: x‑axis categories = “Stay after gain” and “Switch after loss”.
            For each category, two bars: green = good learners, red = bad learners.
            Y‑axis = conditional proportion (0‑1). Compares strategy use between the two learner subgroups.
        
        - subject_vs_group_comparison/ (one PNG per subject)
            For each subject, a bar graph with two blocks (session 1 and session 2). Within each session block, four bars:
                1. dark green = subject win‑stay
                2. light green = group win‑stay
                3. dark red = subject lose‑switch
                4. light red = group lose‑switch
            Allows direct visual comparison of the subject’s strategy proportions against the group norms for both sessions.

12. /slope_analysis/
    Created by: learning_slope_analysis.py
    Contains:

    - trial_level_data.csv
        Columns: Subject, Session (Pre/Post), Block, Trial, Correct (1/0), LearnerType (good/bad).
        Raw trial‑by‑trial data for every subject across both sessions. This is the foundation for all
        slope calculations and can be reused for additional models (e.g., win‑stay analysis).

    - learning_slopes.csv
        Columns: Subject, LearnerType, slope_pre, slope_post, delta_slope (Post − Pre).
        For each subject, the linear learning slope (proportion increase per trial) estimated
        from their learning curve in the Pre and Post sessions. A negative delta indicates
        slower learning after VR stress.

    - analysis_results.txt
        A single text file containing all statistical outcomes:
            * Individual subject slopes table (Pre, Post, Delta, LearnerType)
            * Paired t‑test results for All subjects, Good learners, and Bad learners:
              mean slopes, t‑statistic, p‑value, and Cohen's d (negative d = slower after stress)
            * Linear mixed model summary: Correct ~ Trial × Session with random subject intercept.
              The key coefficient is Session[Post]:Trial – a negative value indicates a flatter
              learning slope after VR stress.
            * List of all saved graphs with file paths.

    - mixed_model_summary_raw.txt
        Full output table of the linear mixed model (Correct ~ Trial × Session).
        Contains coefficients, standard errors, z‑values, p‑values, and random effects.
        The interaction term Trial × Session[Post] tests whether the learning slope
        changed after stress.

    - slope_figures/
        Contains all graphs generated by the script:
        
        * paired_slopes_all_groups.png
            Three subplots (All subjects, Good learners, Bad learners) showing Pre and Post
            learning slopes as bars with ±SEM. Overlaid are jittered individual subject points,
            with grey lines connecting each subject’s Pre and Post slope. This visualises the
            direction and consistency of slope changes at the group level.

        * learning_curves_all.png, learning_curves_good.png, learning_curves_bad.png
            For each group (All, Good, Bad), observed proportion correct per trial (points
            with ±SEM error bars) and linear fit lines for Pre (solid) and Post (dashed).
            The fitted slope value is annotated on each line, making the learning rate
            difference visually apparent.

        * individual_curves/
            Contains one PNG per subject: subject_<id>_learning_curve.png.
            For each subject, Pre and Post observed proportions (points) and their linear fits
            (dashed lines), with slopes labelled. The subject's learner type (good/bad) is
            shown in the title. This helps identify subjects whose learning patterns changed
            dramatically after stress.

    Interpretation of key outputs:
        - Learning slope = the average increase in proportion correct per trial (0‑1 scale).
          A positive slope indicates learning; a negative slope indicates worsening; zero
          indicates no change.
        - Delta_slope = Post − Pre. Negative = slower learning after stress (supports hypothesis).
        - Paired t‑test p < .05 with negative mean delta = significant slowing of learning.
        - Cohen's d: 0.20 = small, 0.50 = medium, 0.80 = large effect size.
        - Linear mixed model: a negative coefficient for Session[Post]:Trial means the
          slope is flatter in the Post session, indicating slower learning after stress.
        - Negative slopes near zero (e.g., –0.001) are typically noise – check confidence
          intervals to determine if they are significantly different from zero.

    All outputs are saved in /learning_rates/outputs/slope_analysis/

13. /group_average_by_winner/
    Created by: group_average_by_winner.py
    Contains:
        - group_average_by_winner_session1.png
        - group_average_by_winner_session2.png

    Description:
        For each session (1 and 2), a single figure showing the group average
        proportion of correct (set‑winner) choices separately for trials where
        the set‑winner was a face (blue) versus a house (red).

        x‑axis = trial number (1‑18)
        y‑axis = proportion correct (0‑1)
        Observed group means at each trial are shown as points (with error bars
        representing ±1 SEM). An exponential curve is fitted to each line when
        at least 4 valid data points exist; otherwise a simple linear interpolation
        is used. Shaded bands around the fitted curves represent the interpolated
        SEM.

        The dashed gray horizontal line marks chance (0.5). The plot title
        indicates the session number.

    Interpretation:
        This graph reveals whether learning differs depending on the type of
        stimulus that was rewarded. If the face curve (blue) is consistently
        higher than the house curve (red), subjects may have preferentially
        learned face‑reward associations. Conversely, if the two curves
        overlap, learning is comparable for both stimulus categories.

        Comparing across sessions can show whether any bias changes after
        the VR stress (e.g., if the post‑stress curve shows reduced
        discrimination between face and house winners).

    All outputs are saved in /learning_rates/outputs/group_average_by_winner/
