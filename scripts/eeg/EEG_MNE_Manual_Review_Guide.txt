MANUAL REVIEW OF SAVED PREPROCESSED EEG

Run these commands from your Puberty_VR project root.

1. Generate the preprocessed recording, automatic decisions and PSD outputs.

   python3 scripts/eeg/EEG_Audit.py

   Subjects 039–052 use the second half of every recording by elapsed time.
   Each channel uses complete 2-second epochs stepped every second.
   Automatic rejection uses +/-200 µV on offset-corrected input and
   notch-filtered EEG. The default raw offset is 725 µV for Muse exports.

2. Open the actual saved preprocessing.

   python3 scripts/eeg/EEG_Manual_Review.py --subject 039 --phase pre_vr

   The viewer loads data/processed/eeg/sub039/039_pre_vr_eeg_Preprocessed.npz.
   It preserves the selected timeline, shows the filtered waveform and shades
   automatically rejected windows. Rejected epochs are excluded from spectral
   summaries and remain available for review on their original time axis.

   For an existing saved NPZ anywhere else, use --input /full/path/file.npz.
   Missing preprocessing is an error. The viewer does not process the raw file
   again as a substitute.

3. Inspect a particular time or channel.

   python3 scripts/eeg/EEG_Manual_Review.py --subject 039 --phase pre_vr --start 180
   python3 scripts/eeg/EEG_Manual_Review.py --subject 039 --phase pre_vr --channel AF8

   --start is ORIGINAL recording elapsed seconds. The program reports the
   original time range of the selected continuous span. The GUI x-axis is
   time within that span. Gaps separate review spans; use --start to open the
   other spans. Without --start the longest eligible span is shown.

   --scale-uv 200 sets the amplitude display range. Display scaling does not
   change the saved samples or exclusion thresholds.

4. Add human annotations and close the window to save.

   Press A in the MNE browser. Add labels such as BAD_blink, BAD_muscle,
   BAD_contact or BAD_clipping_suspected. Drag over the visible disturbance.
   Use REVIEW_uncertain to record uncertainty without excluding that interval.

   BAD_auto_ labels identify automatic rejections. Their automatic decisions
   remain in the saved epoch ledger. They are recreated on each review run.
   Choose AF7 or AF8 for channel-specific human decisions. An unscoped label
   in the paired viewer applies to AF7 and AF8.

5. Find the review files in outputs/eeg/manual_annotations/sub039/.

   Filenames include the recording, channel selection, processing identity
   and continuous span. The FIF reopens the labels. The intervals CSV includes
   display seconds, original recording seconds, source timestamps, channel
   scope, reviewer notes and the full preprocessing ID. The PDF shows the
   annotated filtered traces in microvolts.

   Existing notes are preserved when reopening the same review. The default
   output folder is also the folder scanned by the preprocessing pipeline.
   If using a custom --output-dir, copy its intervals CSV into the default
   subject annotation folder before the next audit.

6. Apply the human BAD_ intervals to final PSD and band estimates.

   python3 scripts/eeg/EEG_Audit.py
   python3 scripts/eeg/process_all_eeg.py
   python3 scripts/eeg/summarize_eeg.py

   Each full epoch overlapping a matching human BAD_ interval is rejected for
   its affected channel. Paired power requires both channels to pass. The
   collector uses these same decisions. Recording approvals and manual notes
   are tracked separately in outputs/eeg/audit/eeg_manual_review.csv.

   A changed source, crop or processing setting creates a new preprocessing
   ID. The viewer opens a new review filename. Old IDs and raw-based reviews
   are reported as ignored rather than moved to a different time coordinate.
   The analysis ID additionally tracks the human interval exclusion set.

READING THE PLOTS

The spectrogram shows frequency versus original recording time. Color is
PSD in dB relative to 1 µV²/Hz. Each estimate covers a fixed two-second epoch.
Epoch starts are separated by one second. Blank cells are excluded epochs.
Use the waveform to set event boundaries, because a short artifact can
affect multiple overlapping epochs. The fixed shared color scale allows
comparisons between the two frontal panels.

Check the native acquisition units and offset before interpreting the
amplitude threshold. For already signed µV data, generate preprocessing
with EEG_Audit.py --raw-offset-uv 0. The reviewer uses the units and offset
recorded in the saved metadata.

Install dependencies if needed.

   python3 -m pip install numpy pandas scipy matplotlib mne

See EEG_Audit_README.md for the full output definitions and methods.
